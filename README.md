# inkstroll-pages

Static files served by GitHub Pages for the Inkstroll app.

- `lodging/<x>/<y>.json`: places to stay for one cell of the zoom-8 Web Mercator grid, built by `tools/overture/build.py` in the app's repository from Overture Maps' Places theme (CDLA Permissive 2.0, Apache 2.0). `lodging/index.json` names the release.
